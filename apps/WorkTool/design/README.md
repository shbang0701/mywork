# WorkTool 디자인 값 3판

## 1. 3판 요약

- 파스텔 바탕 7색 위에 테두리 없는 흰 카드를 놓습니다. 2026-10-31 시안 3(파스텔)으로 확정했습니다.
- 파스텔 하나는 옅은 색(`Tint`)과 강조색(`Accent`) 두 값입니다. 면 · 선 · 조작색은 이 두 값에서 계산합니다. 글자 · 입력 테두리 · 상태색은 일곱 색 모두 같은 고정값입니다.
- 창 아래 상태 줄을 없앴습니다. 메뉴와 내용 사이 선도 없습니다.
- 달력은 평소 근무일을 표시하지 않고, 업무외 · 휴가 · 휴무일만 숫자 바탕을 옅게 칠합니다.
- 화면 제목과 홈 날짜(20 · 24)는 보통 굵기입니다. 맑은 고딕 Bold가 무겁기 때문입니다. 메모 본문의 제목은 4절 메모 단계를 따릅니다.
- 화면 값은 이 문서가 기준입니다. 없는 값은 [apps/design.md](../../design.md)를 따르고, 새 값이 필요하면 이 문서에 먼저 더합니다. 2판에서 바뀐 내용은 12절에 있습니다.
- 그림자 · 흐림 · 그라데이션 · 애니메이션과 둥근 안쪽 Clip은 쓰지 않습니다.

![WorkTool 3판 화면](v3-home.png)

그림 경로: `apps/WorkTool/design/v3-home.png`. 일정 · 근태 · 메모는 같은 폴더의 `v3-schedule.png` · `v3-attendance.png` · `v3-memo.png`입니다.

**읽는 약속**

- 단위는 px = WPF DIP, 배율 100%입니다. 좌표는 바깥 테두리의 왼쪽 위 기준입니다. SVG의 `x+0.5`, `width-1`은 1px 선의 중심 좌표이므로 바깥 크기로 환산합니다.
- 색은 `B.*`, 크기·줄 높이는 `F.*`, 글꼴은 `Font.*` 이름으로 참조합니다.
- C · B는 2판 시안 이름입니다(C = 콘솔형, B = 생산성형). 값은 이 문서에 옮겨 적었고, 시안 원본은 저장소에 없습니다. 「C SVG」 같은 말은 그 값의 출처를 뜻합니다.
- 1판 · 2판의 그림과 체험 파일은 과거 기록입니다. 그 안의 값 · 배치를 쓰지 않습니다.

- 표·목록은 아이콘만 상태색이고 글자는 `B.Text.Primary`입니다. 배지에만 연한 상태 바탕을 쓰며 행 전체를 칠하지 않습니다.

## 3. 파스텔 7색

설정의 `theme.color`에 저장합니다. 기본은 하늘입니다. 값을 모르면 저장 값은 그대로 두고 하늘로 표시합니다. 2판의 `theme.accent`는 파일에 남아 있어도 읽지 않습니다.

| 이름 | 키 | 옅은 색 `T` | 강조색 |
|---|---|---|---|
| 하늘 (기본) | `sky` | `#DCEBFA` | `#226EBE` |
| 분홍 | `pink` | `#FADDE8` | `#B83D69` |
| 연두 | `green` | `#E1F1CF` | `#3F7D20` |
| 노랑 | `yellow` | `#FBEDBF` | `#856000` |
| 보라 | `purple` | `#E9E0F8` | `#7048B8` |
| 회색 | `gray` | `#E3E7EC` | `#56606D` |
| 검정 | `black` | `#DEDFE2` | `#2B2F36` |

- 색 하나를 더하려면 `core/Theme.psm1`의 `$script:palettes`에 한 줄을 더합니다. 면 · 선은 계산되고, 대비는 검사(`Test-Core.ps1`)가 7색 모두 확인합니다.
- 일곱 색 모두 다음을 지킵니다: 본문 · 보조 · 3차 글자는 모든 면에서 4.5:1 이상, `B.Accent.Text`는 글자가 놓이는 면에서 4.5:1 이상, 입력 테두리는 3:1 이상.
- 하늘의 강조색은 1판 `#2370C2`였습니다. `B.Bg.Selected` 위 글자가 4.5:1에 못 미쳐 `#226EBE`로 어둡게 했습니다.
- 상태색 · 달력 종류색은 파스텔과 관계없이 고정입니다.

## 4. 글자 단계

- `Font.UI` = `Segoe UI Variable Text, Segoe UI, Malgun Gothic`.
- `Font.Mono` = `Consolas, Malgun Gothic`.
- `Font.Icon` = `Segoe Fluent Icons, Segoe MDL2 Assets`.
- 굵기는 Regular 400과 SemiBold 600입니다. 한글 600은 맑은 고딕에서 Bold로 보입니다. 12/600은 작은 달력의 오늘 날짜 · 다음 일정 알약 · 시간 막대의 다음 일정 이름만 예외입니다. 시각·숫자 열은 고정폭 숫자입니다.

## 5. 간격·모서리·선·높이

### 간격

- `F.Space.1` 4, `F.Space.2` 8, `F.Space.3` 12, `F.Space.4` 16, `F.Space.6` 24, `F.Space.8` 32.
- `F.Gap.InGroup` 4 또는 8은 부품별 지정값을 따릅니다. 버튼 사이는 8입니다.
- `F.Gap.Panel` 8: 카드 사이, 창 오른쪽 · 아래 여백입니다. 카드에는 테두리가 없고 이 간격으로 나눕니다.
- `F.Padding.Card` 가로 20 · 세로 16: 카드 안쪽입니다. 일정 달력 · 근태 표는 격자를 넓게 쓰려고 좌우 16입니다. `F.Padding.Panel` 12는 좁은 패널 안쪽입니다.
- SVG에 직접 있는 10(입력 글자 시작), 20·28(부품), 44(메모 본문 옆 여백), 52·60(행)은 일반 간격 단계가 아닌 해당 부품의 전용 값입니다.

### 모서리·선

- `F.Radius.Joined` 0: 표의 선택 행·탭 아래.
- `F.Radius.Small` 2: 체크 상자·달력 칩·작은 막대.
- `F.Radius.Control` 4: 버튼·입력·배지·B 메모 탭.
- `F.Radius.Card` 8: 카드.
- `F.Radius.Overlay` 8: 메뉴·대화상자·펼침 패널.
- `F.Radius.SelectionBar` 1.5: C SVG의 폭 3인 선택 막대만의 예외입니다.
- `F.Line.Border` 1, `F.Line.Focus` 2, `F.Line.FocusInner` 1, `F.Line.Selection` 3, `F.Line.TabActive` 2.
- 선택 막대는 3×16, 현재 시각 선은 2×28입니다.
- 그림자·흐림·그라데이션·애니메이션은 모두 없음입니다. 상태는 즉시 바꿉니다. 둥근 안쪽 Clip·둥근 `ClipToBounds` 처리는 금지하며 테두리만 둥글립니다.

### 높이

- `F.Height.Control` 32: 기본·강조 버튼, 입력, 고르기 칸, 메뉴 항목, 표 행, 한 줄 목록.
- `F.Height.Compact` 28: 작은 찾기 칸·아이콘 버튼·달 이동·분할 버튼.
- `F.Height.Row2` 48: 두 줄 목록. 메모 목록은 B SVG의 `F.Height.MemoRow` 52가 예외입니다.
- `F.Height.PanelHeader` 40, `F.Height.Header` 56(카드 머리줄), `F.Height.Tab` 36(C 공통)입니다.
- 메모는 B의 `F.Height.MemoTabBar` 40, `F.Height.MemoTab` 28을 씁니다. C의 탭 36과 혼용하지 않습니다.
- 높이는 배율·글자 확대 전 기준입니다. 텍스트 확대 시 글자가 잘리면 같은 비율로 늘립니다.

## 6. 창 짜임

### 타이틀바 — B

- `F.Chrome.Height` 32. 바탕 `B.Bg.Canvas`, 찾기 칸·출근 표시·시계는 두지 않습니다.
- 앱 표식은 `(12,8)`의 16×16, 모서리 4, `B.Accent` 바탕·`B.OnAccent` W입니다. W는 B SVG의 10/700인 표식 예외이며 UI 글자 단계가 아닙니다.
- 앱 이름 `WorkTool`: x=36, 기준선 y=20.3, `F.Caption`, `B.Text.Secondary`입니다.
- 오른쪽 창 버튼은 각각 46×32입니다. 최소화 x=`W−138`, 최대화/복원 x=`W−92`, 닫기 x=`W−46`, y=0입니다. 글리프 10, 중앙 x는 `W−115`, `W−69`, `W−23`, 기준선 y=21입니다.
- 창 버튼의 보통·올림·누름·비활성은 7절 아이콘 버튼의 Canvas 상태를 씁니다. 창 단추에 글자 라벨은 없습니다.

### 왼쪽 메뉴 — C

- 메뉴와 내용 사이 선은 없습니다.
- `F.Nav.Width` 200, `F.Nav.CollapsedWidth` 48, 항목 높이 32, 묶음 이름 높이 24, 아이콘 16입니다.
- 펼쳤을 때 행 x=8, 폭 184, 글자 x=48, 아이콘 x=20입니다. 개수 오른쪽 끝 x=184, `F.Caption`·`B.Text.Tertiary`입니다.

## 8. 화면별 값

### 공통

### 달력 표시

작은 달력과 일정 달력이 같은 규칙을 씁니다(`Get-WtCalendarMark`).

| 날 | 숫자 바탕 / 글자 |
|---|---|
| 평소 근무일 · 주말 · 기록 없는 날 | 칠하지 않음 |
| 업무외: 업무외 기록이 있거나 쉬는 날에 근무 기록이 있는 날 | `B.Cal.Overtime.Bg` / `B.Cal.Overtime.Text` |

- 바탕: C의 회색 + 강조색 5개를 없애고 파스텔 7색으로 바꿨습니다. 글자 색은 푸른 회색 계열로 바꿨습니다(일곱 색 공통). 설정 키는 `theme.accent`에서 `theme.color`로 돌아갑니다.
- 짜임: 패널 테두리를 없애고 8 간격의 흰 카드로 나눕니다. 카드 모서리는 8입니다. 상태 줄과 메뉴 옆 선을 없앴습니다.
- 글자: `F.Title`을 400으로 낮추고 `F.Display` 24를 더했습니다.
- 달력: ✔ · X 기호를 없애고 업무외 · 휴가 · 휴무일만 숫자 바탕으로 칠합니다. 평소 근무일과 주말은 표시하지 않습니다. 일정 달력 칸에 휴가 · 업무외 칩을 넣습니다.
- 홈: 제목을 날짜로 바꾸고 다음 일정 줄을 더했습니다. 시간 막대가 카드 폭을 모두 쓰고, 막대 아래에 일정 이름을 씁니다. 지난 · 다음 · 뒤 일정의 색을 나눴습니다. 바로 가기는 테두리 없는 2열 목록입니다. 카드가 창 높이를 채웁니다.
- 일정 · 근태: 사이드바 폭 288. 머리줄이 카드 안으로 들어갑니다.
